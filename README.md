# 周边去哪儿

使用高德地点搜索与步行路线，按明确起点、城市、步行时间上限和偏好，推荐附近最多三个真实地点。

## 使用

在提供高德地图工具的 Agent 环境中加载根目录的 `SKILL.md`。高德地点搜索和步行路线工具由宿主环境提供；本仓库不包含地图服务或 API Key。

示例需求：给定城市与起点坐标，寻找步行十五分钟内的咖啡馆，优先步行距离近的，最多推荐三个。请始终提供真实起点坐标，不使用城市中心代替。

技能将逐个核验从同一起点出发的步行路线，按原始秒数筛选时间上限、去重并排序；查不到路线、超时或未经核实的店铺特点不会被当作已满足条件。候选不足和服务错误会如实说明。
